# Common questions

## Who can edit these docs?

Anyone who has been added as a collaborator. Ask a maintainer for access,
then follow [Using the editor](../guides/using-the-editor.md).

## How long until my change is live?

After it's published from the review queue, about two minutes.

## Can I break the site by editing?

No. Changes go through review before publishing, and every version is kept
in history.

## I prefer editing files directly — can I?

Yes. Developers can edit the Markdown files in the repository as usual.
Both routes end up in the same place.
