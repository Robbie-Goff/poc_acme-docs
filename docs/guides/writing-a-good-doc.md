# Writing a good doc

1. **Lead with the task.** Start with what the reader is trying to do, not
   background.
2. **One page, one purpose.** If a page answers two questions, split it.
3. **Show, don't describe.** A screenshot or example beats a paragraph.
4. **Date your claims.** "As of August 2026, the limit is 50 users."
5. **Delete fearlessly.** Outdated docs are worse than no docs — everything
   is in version history anyway.
