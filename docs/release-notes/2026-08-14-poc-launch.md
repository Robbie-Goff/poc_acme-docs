# POC launched — 14 August 2026

First deployment of the documentation site.

**Included in this release:**

- Public docs site built with MkDocs Material
- Browser-based editing via the content manager at `/admin/`
- Editorial workflow: drafts are reviewed before publishing

**Known limitations under evaluation:**

- Publishing takes a couple of minutes (build + deploy time)
- Simultaneous edits to the same page can conflict
